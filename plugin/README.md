# Aster for Claude Code

Co-edit UML class models with Claude. The model file (StarUML `.mdj`, or `.aster`) lives in your
repository; Aster shows it in a browser tab, Claude and you edit the same diagram, and the file
follows every change, ready to commit.

## Install

```
/plugin marketplace add parsvensson/Aster
/plugin install aster@aster
```

Needs Node 24 or newer on the PATH. Nothing else is installed: the app and the server are in
this folder as built files.

## Use

Open Claude Code in a repository and ask, for example:

> Read src/billing and docs/architecture.md, then suggest changes to docs/model.mdj, view "alpha".

Claude opens the file in Aster (in the desktop app's browser pane, or it gives you a local URL),
shows the view, and edits it with you. See `skills/uml-modelling/SKILL.md` for how Claude works,
and `docs/plugin.md` in the Aster repository for how the plugin is built.

## What is in here

| Path                   | What                                                                        |
| ---------------------- | --------------------------------------------------------------------------- |
| `.claude-plugin/`      | The plugin manifest.                                                        |
| `.mcp.json`            | Starts `server.js` as the session's MCP server.                             |
| `server.js`            | The MCP server, the bridge to the tab, and the file reader/writer, bundled. |
| `app/`                 | Aster, built.                                                               |
| `skills/uml-modelling` | The workflow, for Claude.                                                   |

`server.js` and `app/` are generated by `pnpm plugin:build`; do not edit them by hand.
